# 如何搭建VUE框架

## 环境搭建

1.安装node
安装node.js安装vue前电脑中必须已经安装成功node.js
node.js下载链接

https://nodejs.org/zh-cn/download

下载完成后，执行安装程序，直接进行安装即可
安装完成后，打开命令行窗口（cmd)
输入node-v和npm-v可查看安装的node.js和npm的版本号
2.安装编辑器
建议 vscode
3.安装vue
使用npm进行安装
缺点安装速度慢,因为资源在国外，可以使用国内镜像
使用国内镜像资源安装
首先切换淘宝镜像

```
npm install -g cnpm -registry-https://registry.npm.taobao.org
```

使用npm安装vue的脚手架

```
npm install -g @vue/cli
```



## 创建Vue项目

### 1.创建文件

创建文件夹用vscode打开，点击终端按钮，cd进入到你要创建的文件夹里

使用vite脚手架工具更方便

输入命令

```
npm init vite@latest
```

Vue 项目名**不能包含大写字母**

## 命令

| 命令              | 作用                       | 说明                           |
| ----------------- | -------------------------- | ------------------------------ |
| `npm run dev`     | **开发环境启动**（最常用） | 启动本地服务，热更新，开发时用 |
| `npm run serve`   | 开发环境启动               | Vue CLI 老项目用               |
| `npm run build`   | **生产打包**               | 打包出 `dist` 文件夹，上线部署 |
| `npm run preview` | 预览打包结果               | 打包后本地查看 dist 效果       |
| `pnpm dev`        | 快速启动                   | 用 pnpm 包管理器时             |
| `yarn dev`        | 快速启动                   | 用 yarn 包管理器时             |

### npm run dev



![05](D:\1024实验室\比赛\软件杯01\前端\vue学习\相关图像\05.png)

提示 `press h + enter to show help`：按下 `h` 键回车可查看更多终端快捷指令（如切换端口、清空缓存等）

![06](D:\1024实验室\比赛\软件杯01\前端\vue学习\相关图像\06.png)

| 快捷键      | 英文说明           | 中文作用           | 适用场景                                                     |
| ----------- | ------------------ | ------------------ | ------------------------------------------------------------ |
| `r + Enter` | restart the server | 重启开发服务器     | 配置文件（`vite.config.js`）修改后、环境变量更新后，快速重启生效 |
| `u + Enter` | show server url    | 显示服务器访问地址 | 忘记本地端口（默认 `5173`）、需要复制地址给他人时            |
| `o + Enter` | open in browser    | 在浏览器中打开项目 | 不用手动输地址，一键唤起浏览器打开项目                       |
| `c + Enter` | clear console      | 清空控制台日志     | 终端日志太多、需要清爽界面时                                 |
| `q + Enter` | quit               | 退出开发服务器     | 结束开发、关闭服务（替代 `Ctrl + C`）                        |

注：

**结束开发、关闭服务后**

1.本地服务立即停止

- 无法再通过地址访问项目。
- 浏览器中打开的页面会显示 **无法访问**（This site can't be reached）。

2.终端释放控制权

- 终端回到等待输入状态，你可以重新运行 `npm run dev` 等命令。

| 操作             | 效果                       | 适用场景                   |
| ---------------- | -------------------------- | -------------------------- |
| **`q + Enter`**  | 优雅退出，释放端口         | 正常结束开发、暂时离开电脑 |
| **`Ctrl + C`**   | 强制终止（与退出效果一致） | 服务卡死、无响应时         |
| **关闭终端窗口** | 等同于退出服务             | 彻底结束工作               |

## 注

vscode可能禁止运行脚本，原因：Windows 系统权限问题

解决方案

1.用管理员身份打开 PowerShell，执行这条命令

```
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

输入 `Y` 回车确认

2.直接把 VSCode 终端换成 **CMD** ，在cmd上运行
